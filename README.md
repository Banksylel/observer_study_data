This repo contains per probe site periodontal disease classification evaluations made by 7 dentists of various experience, and prediction made by a separate object detection and landmark detection models trained on the same data.

This data is part of an indendent observer study, evaluating the performance of individual dentists against the inferred diagnosis from all 7 dentists, and against two types of detection methodologies (object detection, and landmark detection with percentage of bone loss calculated).

8 out of distribution external validation images are evaluated.

As part of section 6 (Independent Observer Study) of (Structure-Aware Deep Learning Approaches for Dental Disease Detection in Diagnostic Imaging)[https://openresearch.surrey.ac.uk/esploro/outputs/doctoral/Structure-Aware-Deep-Learning-Approaches-for-Dental/991090728102346]
